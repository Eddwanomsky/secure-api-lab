# secure-api-lab

Цей проєкт є навчальним захищеним RESTful API, розробленим на Node.js з використанням вебфреймворку Express. Додаток надає можливість маніпулювати ресурсами документів та співробітників, використовуючи стандартні HTTP-методи.   У проєкті реалізовано наскрізну логіку за допомогою функцій-middleware: глобальне логування вхідних запитів, аутентифікація користувачів за кастомними заголовками HTTP та рольова авторизація (доступ користувачів з роллю admin до конфіденційних даних).   

## Інструкції з встановлення та запуску
Встановлення залежностейПеред запуском переконайтеся, що на вашому комп'ютері встановлено Node.js та npm. Клонуйте репозиторій та встановіть необхідні пакети:

**clone https://github.com/YourUsername/secure-api-lab.git**

**cd secure-api-lab**

**npm install**

_____________
## Запуск сервера

Для запуску вебсервера виконайте команду: 

**npm start**

Сервер буде доступний за адресою: **http://localhost:3000**
_____________
## Інструкції з запуску тестового клієнта

Для автоматичного перевірки роботи ендпоінтів та сценаріїв безпеки запустіть спеціальний скрипт тестування  

**npm test**
